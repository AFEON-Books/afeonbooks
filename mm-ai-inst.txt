Here is the complete setup and code to implement Option 1. This solution includes a manual master switch (MAINTENANCE_MODE) and an automatic fallback safety net if your main logic completely crashes.

Step 1: Update Your Worker Code

Replace your current Worker code with this structure. It wraps your existing logic safely inside a try...catch block.
javascript
export default {
  async fetch(request, env, ctx) {
    // 1. MANUAL SWITCH: If turned on in Cloudflare dashboard, instantly show maintenance
    if (env.MAINTENANCE_MODE === "true") {
      return serveMaintenancePage();
    }

    try {
      // ------------------------------------------------------------
      // YOUR MAIN WORKER CODE GOES HERE
      // For example, fetching from your origin server or handling routing:
      
      const response = await fetch(request);
      
      // OPTIONAL: If your origin server returns a 502/503 error, catch that too
      if (response.status === 502 || response.status === 503) {
        return serveMaintenancePage();
      }
      
      return response;
      // ------------------------------------------------------------
    } catch (error) {
      // 2. AUTOMATIC FAILOVER: If your code crashes or the fetch fails entirely
      console.error("Main worker crashed or timed out:", error);
      return serveMaintenancePage();
    }
  }
};

Step 2: Add the MAINTENANCE_MODE Variable

To control this without redeploying code every time, you need to add an environment variable in your Cloudflare dashboard.
1. Go to your Cloudflare Dashboard and select Workers & Pages.
2. Click on your specific Worker.
3. Go to the Settings tab ➡️ Variables.
4. Scroll down to Environment Variables and click Add.
5. Set the fields exactly like this:
	• Variable name: MAINTENANCE_MODE
	• Type: Text
	• Value: false (when your site is running normally)
6. Click Save and Deploy.

💡 How to use it going forward

• Normal Operations: Keep the value set to false. Your main app code will run. If your server randomly drops offline, the code will automatically catch it and show the maintenance screen.
• Scheduled Maintenance: When you are ready to do planned work, change the value from false to true in the dashboard and click save. The change takes effect globally within seconds, instantly routing all traffic on your main domain to your maintenance screen.
